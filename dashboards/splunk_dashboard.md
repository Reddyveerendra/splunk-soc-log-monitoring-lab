# Splunk Security Monitoring Dashboard

The Splunk Security Monitoring Dashboard was created to visualize and analyse security-related events collected from the Ubuntu server.
This dashboard helps simulate the workflow of a Security Operations Center (SOC) by providing insights into authentication failures, port scanning activity, and privileged command usage.

The dashboard allows analysts to quickly identify suspicious activities and monitor system behavior in real time.

## Dashboard Overview

The dashboard contains multiple panels that focus on different types of security events:

SSH authentication failures

Successful sudo sessions

Port scanning attempts

Top attacking IP addresses

Frequently targeted ports

These visualizations help analysts quickly detect abnormal patterns and investigate potential security incidents.

## Panel 1: SSH Failed Login Attempts

This panel displays failed SSH login attempts detected in the authentication logs.
Multiple failed login attempts from a single IP address may indicate a brute-force attack.

SPL Query
index=main "Failed password"
| rex "from (?<src_ip>\b\d{1,3}(?:\.\d{1,3}){3}\b)"
| stats count by src_ip
| sort -count

## Panel 2: SSH Brute Force Detection

This panel identifies IP addresses that generate a high number of failed login attempts within a short time period.

SPL Query
index=main "Failed password"
| rex "from (?<src_ip>\b\d{1,3}(?:\.\d{1,3}){3}\b)"
| bucket _time span=5m
| stats count by src_ip _time
| where count > 5

## Panel 3: Sudo Privilege Escalation Activity

This panel tracks the usage of sudo commands. Monitoring privileged access is important because attackers often attempt to escalate privileges after gaining initial access.

SPL Query
index=main "sudo: pam_unix(sudo:session): session opened for user"
| stats count by user
| sort -count

## Panel 4: Port Scan Detection

Port scanning is a reconnaissance technique used by attackers to discover open services on a system.

This panel detects IP addresses that attempt connections to multiple ports within a short time period.

SPL Query
index=*
| stats dc(port) as unique_ports count by src_ip
| where unique_ports > 10
| sort -unique_ports

## Panel 5: Most Targeted Ports

This panel displays the ports that receive the highest number of connection attempts.

SPL Query
index=*
| stats count by port

Security Insights

From the dashboard analysis, several key security observations can be made:

Multiple failed SSH login attempts indicate possible brute-force activity.

Certain IP addresses repeatedly attempt authentication.

Privileged command usage can be monitored through sudo session logs.

Port scanning behaviour can reveal reconnaissance attempts against the system.

These insights help analysts detect suspicious behaviour early and respond to potential threats.

## Conclusion

The Splunk dashboard provides a centralized view of security events generated by the Ubuntu server. By visualizing authentication logs, privilege escalation attempts, and network activity, analysts can quickly identify and investigate potential threats.

This dashboard demonstrates how Splunk can be used as a SIEM platform to monitor and detect security events in a Linux environment.
