# Port Scan Detection using Nmap and Splunk

## Overview

In this step of the SOC lab, a **port scanning activity** is simulated against the Ubuntu server to generate security-related logs. Port scanning is a common reconnaissance technique used by attackers to discover open services on a target system.

The generated logs are then analyzed in Splunk to identify scanning activity and detect suspicious network behavior.

---  

## What is a Port Scan?

A port scan is a technique used to identify open ports and services running on a system. Attackers use port scanning during the reconnaissance phase to discover potential entry points into a network.

Common indicators of port scanning include:

- Multiple connection attempts to different ports
- Rapid scanning activity from a single source
- Unusual connection attempts to closed ports

Monitoring system logs can help detect these activities.

---

## Step 1: Install Nmap on the Host Machine

To simulate a port scan, install **Nmap**, a network scanning tool.

For Ubuntu systems:

sudo apt install nmap -y

For Windows, download Nmap from:

https://nmap.org/download.html

## Step 2: Perform a Port Scan

Run the following command from the host machine to scan the Ubuntu server.

Example:

nmap -sS localhost

This command performs a TCP SYN scan to identify open ports on the target system.

## Step 3: Generate Logs on the Server

The scanning activity generates connection logs that are captured in system logs monitored by Splunk.

You can check the logs directly on the Ubuntu server using:

sudo cat /var/log/auth.log

or

sudo tail -f /var/log/auth.log

## Step 4: Search Port Scan Activity in Splunk

Open the Splunk Search & Reporting interface and run the following search:

index=main

Review the events to identify unusual connection attempts generated by the scan.

## Step 5: Extract Source IP and Port Information

To analyze scanning activity, extract the source IP address and port information.

Example Splunk query:

index=main
| stats dc(port) as unique_ports count by src_ip
| where unique_ports > 5
| sort - unique_ports

This query helps identify the IP address responsible for generating the highest number of connection attempts.
