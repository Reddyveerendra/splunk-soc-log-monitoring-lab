# Security Monitoring and Threat Detection using Splunk Enterprise

This project demonstrates how to build a basic SOC monitoring environment using Splunk to detect suspicious activities from system logs.

## Lab Environment

- Splunk Enterprise
- Ubuntu Linux Server
- rsyslog
- OpenSSH
- Nmap
- Oracle VirtualBox

## Architecture

Attacker Machine → Ubuntu Server → rsyslog → Splunk → SOC Dashboard

## Use Cases Implemented

1. Failed SSH Login Detection
2. SSH Brute Force Detection
3. Port Scan Detection

## Skills Demonstrated

- SIEM Monitoring
- Log Analysis
- Threat Detection
- Splunk SPL Queries
- Security Monitoring
