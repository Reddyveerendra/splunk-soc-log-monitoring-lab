# SOC Lab Environment Setup using VirtualBox

## Overview
The SOC lab environment was created using Oracle VirtualBox to simulate a real-world infrastructure for security monitoring and log analysis.

---

## What is a Virtual Machine?

A Virtual Machine (VM) is a digital version of a computer that runs inside another computer using virtualization software. It allows users to create separate computing environments on a single physical machine.

Key characteristics of a VM:

- Multiple operating systems can run simultaneously on a single physical machine.
- Each virtual machine behaves like a separate computer with its own system settings and resources.
- Virtual machines share the host system's hardware such as CPU, memory, storage, and network through virtualization technology.
- Common virtualization platforms include:
  - VirtualBox
  - VMware
  - Hyper-V
